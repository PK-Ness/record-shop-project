---------------------------------------------------------
| Hello everyone! Welcome to my Record Shop API Project! |
----------------------------------------------------------

This project is intended to maintain my Record Shop database updated 

FEATURES:
  - Check all of our catalogue in stock;
  - Find albums by their ID;
  - Add new albums to the database;
  - Updated album details;
  - Delete albums from the database;
  - Filter search by album name, artist, genre and release year;

FUTURE IMPLEMENTATIONS:
  - Testing;
  - In-Memory Database;
  - Reafactoring;
